### Highlights

- aide now manages the whole cross-agent environment in one place: Skills, MCP servers, model profiles and per-project configs, with drift detection, an audit trail, snapshots and portable environment bundles.
- A new Health page reports the state of every integration and repairs it in one click.
- Review upstream skill changes before applying them, and move a complete environment to another machine with `.aidebundle` files.

### Features

**Skills**
- Manage skills for 40+ AI tools (Claude Code, Cursor, Codex, Gemini CLI, OpenCode, Windsurf, Zed, Cline, Roo Code, Kilo Code, Goose, Warp, GitHub Copilot, Trae, Qwen Code, iFlow, Kimi, MiniMax, CodeBuddy, Qoder, Lingma and more) from the central `~/.agents/skills` store, linked with symlinks (junctions on Windows, symlinks on Linux).
- Browse and install skills from the skills.sh registry with provenance and upstream commit tracking; update checks are deduped and cached.
- Review updates before applying them: the dialog shows file-level added / changed / removed entries against the pinned upstream commit and warns when the local copy was modified.
- Project profiles: `<project>/.aide/project.json` declares the skills, MCP servers and tools a repository needs; one sync links selected skills into `.agents/skills` and each selected tool's project directory and merges project-level MCP configs. Only links and entries aide created itself are ever removed.
- Tagging, full-text search, a file tree with context menu and keyboard navigation, and a multi-tab CodeMirror editor.

**MCP and agent access**
- Central MCP configuration with import and sync to 8+ tools across JSON, JSONC and TOML, per-OS config paths, and a shared OpenCode `jsonc`/`json` resolution.
- Managed manifest and drift detection: `~/.aide/mcp-managed.json` records what aide wrote, so disabling or deleting a server removes exactly those entries from every tool config; the Health page can clean leftover entries.
- Bundled `aide-mcp` sidecar: MCP stdio server and CLI over the same core (list, search, install, update, sync, publish, pull), with a redacted audit log at `~/.aide/audit.jsonl` (rotated at 2 MB) and `AIDE_MCP_ALLOW_INSTALL` / `AIDE_MCP_ALLOW_PUBLISH` allowlists.

**Models**
- Provider profiles backed by models.dev (200+ providers) with locally stored API keys, optional base URL and per-profile model selection; sync to Claude Code environment, OpenCode providers and Codex `config.toml`.

**Git backup**
- Scoped git backup: separate remotes for personal and company skills. Publish refuses empty scopes, preserves repository files and rescues teammate-pushed skills; pull only writes back the scope's own skills.
- Deterministic git resolution (environment override, PATH, Homebrew/usr paths) for Finder-launched apps, plus URL and branch-ref validation.

**Health, safety and portability**
- Health page and doctor report: aggregated skills, tools, MCP, models, config and agent status with one-click repairs and periodic refresh while visible.
- Environment snapshots: capture and restore central configs under `~/.aide/snapshots` (20 retained); restore always takes a safety snapshot first and reports skill drift without touching skill contents.
- Portable environment bundles (`.aidebundle`): export and import skills, MCP servers and model profile summaries for moving to another machine, with merge or replace modes. API keys and secret-looking MCP values are always redacted and a safety snapshot is taken before importing.
- Environment audit trail for agent and high-risk operations; path-scoped file commands; owner-only tool configs.

**Editor and UI**
- Markdown preview renders GFM tables, opens external links in the system browser and resolves relative images and file links inside the skill.
- Reliable editor state: switching tabs never loses edits, and unsaved changes are guarded when leaving a skill, switching tools or navigating away.
- English and Chinese UI, system/light/dark theme with live OS theme changes, accessible roles and keyboard handling, and aria-live toasts.
- In-app update checks, download and install via tauri-plugin-updater.

### Bug Fixes

- Editing: fixed lost edits when switching tabs, missing dirty indicators and ineffective close confirmations by making the CodeMirror document the single source of truth.
- Config safety: writes are atomic with backups; corrupt `mcp.json`, `models.json` and `remotes.json` are reported instead of being reset to defaults; unparsable tool configs are never overwritten.
- Sync safety: `sync_tool` backs up conflicting tool-side skills and keeps the replaced directory instead of deleting it.
- Publish and pull no longer delete remote or local skills on empty scans or cross-scope conflicts.
- Registry installs are named from SKILL.md, pinned to a commit, enforce archive/extraction limits, and swap staged directories instead of deleting first.
- File operations: `create_file` no longer truncates existing files, `rename_entry` no longer overwrites, and `delete_entry` no longer falls back to permanent deletion.
- Markdown and UI fixes: GFM tables, stale search responses, Cmd+W scoping, palette Escape handling, dialog focus, and many keyboard/accessibility issues.
- Theme: fixed system theme detection and live OS theme changes after the Radix UI migration.

### Behavior Changes

- Corrupt central configs now surface as errors; a damaged config will not be silently reset to defaults.
- Disabling or deleting an MCP server now removes it from tool configs on the next sync (previously the stale entries stayed behind).
- `create_file` fails when the path already exists; `rename_entry` refuses to overwrite; `delete_entry` reports an error instead of permanently deleting when the system trash is unavailable.
- File commands are restricted to the home directory (plus skill folders that are symlinks pointing outside it) and deny sensitive paths such as `~/.ssh`, `~/.gnupg` and `~/.aws`; text reads are capped at 5 MB.
- Synced tool configs are written owner-only (0600 on unix).
- Agent access is only reported as enabled when the registered command still points at the running binary, so re-enable it after moving the app.

### Internal

- Headless logic extracted into the `aide-core` crate; the Tauri command layer is thin and `aide-mcp` links the core crate only, without Tauri or WebKit.
- CI now runs typecheck, ESLint (0 warnings, rules as errors), Vitest, `cargo fmt --check`, clippy with `-D warnings` and tests for both Rust crates.
- Long-running commands moved off the IPC thread; skill scans and update checks are cached; persistence goes through a shared atomic-write and backup module.
